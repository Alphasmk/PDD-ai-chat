## Требование и согласованное решение

Вынести роли в отдельную модель и таблицу `roles`. Ролей ровно две: `user` и `admin`.
Пользователь подтвердил: сохранить защищённого суперадмина как администратора с отдельным признаком `is_superadmin=true`, прежними полномочиями и защитой от удаления, блокировки и смены роли.
Связь пользователя с ролью — `users.role_id`. Миграция должна сохранить существующие аккаунты и преобразовать прежнюю роль `superadmin` в `admin` с этим признаком.
Ранее пользователь также просил использовать `.env` для рабочих переменных; тестовые настройки предназначены только для изолированных тестов. Рабочие секреты не выводить.
